# 合规报告功能说明文档

本文档详细介绍了Compliance-to-Code系统的合规报告自动生成功能，包括其技术实现、使用方法以及展示效果。

## 1. 功能概述

合规报告功能是Compliance-to-Code系统的重要组成部分，它能够在完成合规检查后，自动生成专业、全面的合规分析报告。主要特点包括：

- **智能化分析**：使用大语言模型对合规检查结果进行深度分析和总结
- **专业化呈现**：生成结构化的Markdown格式报告，包含统计数据、案例分析和建议
- **自动化流程**：在合规检查完成后自动异步生成，无需人工干预
- **多端展示**：可在Web界面直接查看，也可以下载为独立文件进行存档

## 2. 技术实现

### 2.1 核心组件

合规报告功能由以下核心组件实现：

- **`tools/compliance_report.py`**：报告生成的主要逻辑实现，包括提示词构建、LLM调用和文件处理
- **`tools/call_gpt.py`**：大语言模型API调用的封装，处理与LLM的交互
- **`tools/execution_engine.py`**：集成了报告生成功能，在检查完成后自动触发报告生成
- **`backend/app.py`**：提供了API接口，用于获取和下载合规报告
- **前端组件**：负责渲染和展示Markdown格式的报告，以及提供下载功能

### 2.2 数据流程

报告生成的完整流程如下：

1. 用户通过Web界面或命令行执行合规检查
2. `ExecutionEngine` 完成检查并保存结果文件
3. 检查完成后，引擎异步启动 `compliance_report.py` 的报告生成流程
4. 报告生成器分析JSON结果，提取关键信息构建提示词
5. 调用大语言模型API生成初步报告内容
6. 将生成的报告内容保存为Markdown文件
7. 前端从API获取报告内容并渲染显示

## 3. 报告内容结构

典型的合规报告包含以下几个主要部分：

1. **报告标题和摘要**：简明扼要地概述公司合规状况
2. **检查背景**：包括公司名称、适用法规和检查时间范围
3. **合规状况分析**：详细分析违规情况，包括违规单元数量和类型
4. **具体违规案例**：详细描述发现的前几个违规案例，分析违约原因
5. **建议和改进措施**：针对发现的问题提出具体的改进建议
6. **结论**：总结报告发现并提出合规管理的总体建议

报告中还可能包含图表、表格等可视化元素，以更直观地展示违规情况。

## 4. 使用方法

### 4.1 通过Web界面查看

1. 通过Web界面执行合规检查
2. 检查完成后，系统会自动生成报告
3. 报告会显示在右侧下方的"合规报告"区域
4. 如果报告尚未生成完成，会显示"正在生成报告，请稍候..."
5. 报告生成后，可以直接在页面上查看

### 4.2 下载报告文件

1. 在Web界面左侧找到"下载"部分
2. 点击"MD"按钮下载Markdown格式的报告文件
3. 点击"JSON"按钮可以下载原始的JSON检查结果

### 4.3 通过命令行工具生成

执行合规检查后，报告会自动生成在结果目录中：

```bash
python main.py check --company <公司名称> --regulation <法规ID>

# 报告将被保存在以下位置：
# results/<时间戳>_<公司名称>_<法规ID>/compliance_report.md
```

也可以单独生成某个已有结果的报告：

```bash
python -m tools.compliance_report <结果文件夹名称>
```

## 5. 展示效果

合规报告在前端显示时，支持以下Markdown格式元素：

- 标题和副标题（多级）
- 表格
- 列表（有序和无序）
- 粗体、斜体等文本格式
- 水平分割线
- 代码块
- Mermaid图表（如饼图、流程图等）

## 7. 常见问题

### 报告生成时间较长怎么办？
报告生成涉及复杂的LLM调用，可能需要几十秒时间。系统设计为异步生成，不会阻塞用户界面，您可以继续使用系统的其他功能。

### 报告显示格式异常怎么办？
如果报告中的Markdown格式显示异常，可以尝试下载报告文件，使用专业的Markdown编辑器查看，或者尝试刷新页面重新加载。
